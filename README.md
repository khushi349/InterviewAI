# InterviewAI

An AI-powered mock interview platform that helps college students and fresh graduates practice realistic interviews and receive structured feedback on their answers.

## 🚀 Live Product

**Try InterviewAI:**
https://interviewai-mock-pla-47tl.bolt.host/

## 🎯 Problem

Students have access to plenty of interview questions and sample answers, but static preparation does not provide the experience of interacting with a real interviewer.

InterviewAI aims to bridge this gap by providing a realistic AI-powered mock interview experience with immediate feedback.

## 💡 Solution

InterviewAI simulates an interviewer using an AI avatar that:

* Asks interview questions
* Allows users to answer using voice or text
* Evaluates responses
* Provides structured feedback
* Helps users identify areas for improvement
* Allows users to practice again

## ✨ Key Features

* Interactive AI interviewer/avatar
* Voice and text-based answers
* 3-question mock interview
* Structured answer evaluation
* Per-question feedback
* Final performance summary
* User feedback collection
* Demo Mode when live AI evaluation is unavailable

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* AI-powered evaluation
* Web Speech APIs for voice interaction

## 📊 Validation

InterviewAI was tested with real users to understand whether the experience felt useful and realistic.

Validation focused on:

* Interview completion
* Usefulness of feedback
* User experience
* Willingness to practice again
* User suggestions and pain points

> Validation results are based on actual user feedback and are not fabricated.
